Formulário de Solicitações - Departamento Pessoal (R7)
Descrição

Aplicação desenvolvida em HTML, CSS e JavaScript para padronizar o envio de solicitações ao Departamento Pessoal da R7 Serviços Contábeis.

O objetivo é reduzir erros no envio de informações, garantir que todos os dados necessários sejam informados e gerar automaticamente um resumo em Markdown, pronto para ser enviado por e-mail, WhatsApp ou utilizado como registro interno.

Funcionalidades
Cadastro da empresa e do colaborador.
Solicitações de:
Admissão;
Desligamento;
Férias;
Outros assuntos.
Cálculo automático da data de retorno das férias.
Lista de documentos para admissões.
Máscaras automáticas para CPF e CNPJ.
Geração automática de resumo em Markdown.
Botão para copiar o resumo para a área de transferência.
Interface simples, organizada por abas e responsiva.
Como utilizar
Abra o arquivo HTML em qualquer navegador moderno.
Preencha os dados da empresa e do colaborador.
Selecione a aba correspondente ao tipo de solicitação.
Informe os dados solicitados.
Clique em Gerar Resumo em Markdown.
Copie o texto gerado e envie ao Departamento Pessoal.
Tecnologias utilizadas
HTML5
CSS3
JavaScript (Vanilla)

Não é necessário instalar programas, bibliotecas ou servidores. Basta abrir o arquivo HTML no navegador.

Benefícios
Padroniza as solicitações.
Reduz informações incompletas.
Agiliza o atendimento do Departamento Pessoal.
Facilita o registro e a conferência das solicitações.
Gera um resumo pronto para compartilhamento.
